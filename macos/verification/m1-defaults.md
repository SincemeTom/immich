# 默认设置（按这台安装的现有配置）

- 日期：2026-10-30
- 分支：`mac/feat/my-defaults`
- 结论：**通过**。新安装、新用户直接就是现在这台 Mac 上的配置，不用再一项项去设

## 默认值

| 设置 | 上游默认 | 现在的默认 | 在哪里设 |
|---|---|---|---|
| 存储模板 | 关闭，`{{y}}/{{y}}-{{MM}}-{{dd}}/{{filename}}` | **开启，`{{y}}/{{MM}}/{{filename}}`** | 代码默认值（`config.dto.ts`） |
| 优先使用嵌入式预览（RAW） | 关 | **开** | 代码默认值（见 [m1-raw-preview.md](m1-raw-preview.md)） |
| 视频转码 | 不用硬件加速，并发 1 | **VideoToolbox，并发 2** | `install.sh` 对新照片库设置一次（依赖本机硬件，见 [m2-videotoolbox.md](m2-videotoolbox.md)） |
| 智能搜索模型 | ViT-B-32 | **XLM-Roberta-Large-ViT-H-14** | `install.sh` 对新照片库设置（见 [m1-clip-model.md](m1-clip-model.md)） |
| 功能 → 文件夹 | 关，不在侧边栏 | **开，在侧边栏** | 用户偏好默认值（`preferences.ts`） |
| 功能 → 人物 / 回忆 | 不在侧边栏 | **在侧边栏** | 同上 |
| 自动堆叠 | 关 | **开**：连拍、RAW+JPG、编辑版、相似照片（0.06，600 秒）、不限拍摄时间（0.03） | 同上 |

"不限拍摄时间"的三档相应调整为：仅完全相同 0.01、严格 0.02、**推荐 0.03**（原来的"宽松"一档去掉）。

## 影响

- 这台 Mac 上现有的设置不变：它们原本就是这些值
- 设置页上"恢复默认"会恢复到这些值
- 没有改过这些设置的其他用户，会按新的默认值生效（目前只有一个用户）
- 存储模板只影响之后上传的照片；已有照片要搬到新结构，在任务队列里执行"存储模板迁移"。外部库的照片不受存储模板影响
