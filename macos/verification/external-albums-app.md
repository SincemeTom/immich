# 外部相册（原“群晖照片”）：改名，以及手机 App 设置和人物封面

- 分支：`mac/feat/pixcellar`
- 日期：2026-11-05
- 结论：群晖相册同步对用户改叫“外部相册”，网页、服务器返回的提示和手机 App 里都不再出现第三方品牌名；“特色照片 / 个性头像”统一叫“人物封面”。Pixcellar 新增 设置 → 外部相册（和网页的功能一样）和人物页菜单里的“选择人物封面”。服务器单元测试 64 项、网页 15 项、App 新增 22 项（全部 1676 项）通过。真机上和正式服一起看还没做，见文末

## 改名

| 原来 | 现在 | 说明 |
|---|---|---|
| 群晖照片（设置标题） | 外部相册 / External albums / 外部相簿 | 功能名 |
| 群晖账号、群晖地址 | NAS 账号、NAS 地址 | 账号仍是 NAS 上的账号，只是不写品牌 |
| DSM | NAS 管理页面 | 例如“请在 NAS 管理页面的‘安全性 → 允许/封锁列表’里解除” |
| 群晖照片（NAS 上的相册应用） | NAS 相册应用 / the NAS photo app | |
| 这个地址不是群晖 | 这个地址不是受支持的 NAS | 目前只支持群晖，但不写出来 |
| 网络共享、存储位置的说明里的“群晖：控制面板 > …” | “在 NAS 上：控制面板 > …”“一般在 控制面板 > …” | 菜单路径照旧，便于照着操作 |
| 设置为特色照片、选择个性头像、更换人物封面照片成功、无法设为封面 | 设为人物封面、选择人物封面、人物封面已更换、无法设为人物封面 | 和“设为相册封面”一个说法；英文 Set as cover photo、Select cover photo；繁体同步 |
| 简体中文里剩下的“外部库” | 外部图库 | 补上 `6e48b20e3` 统一用词时还没合进来的 4 条 |

不改的：文案的 key、接口路径（`/synology/...`）、代码里的名字、钥匙串里的条目名（改了会读不到已存的密码）、接口文档的描述、`macos/` 下的开发文档。服务器返回给用户看的提示（网页在错误下面用小字显示）一起改了，例如 `The NAS answered with error 403`、`No NAS account is bound`。

## 手机 App：外部相册

设置 → 外部相册，和网页 账号设置 → 外部相册 一样：

| 部分 | 做法 |
|---|---|
| 没绑定 | NAS 地址、NAS 账号、密码、校验 HTTPS 证书；三项都填了才能点“绑定”。NAS 要两步验证时出现验证码框，填 6–8 位数字再点一次 |
| 改账号 | 地址和账号没变时密码可以留空，沿用服务器上存的；地址按网页的规则比较（没写协议当 https，只比 origin） |
| 已绑定 | 账号 · 地址，上次连接时间和相册数，没校验证书时提示；上次出错的原因和 NAS 的原话；解除绑定（先确认）、编辑、测试连接 |
| 同步 | 每天同步开关、同步时间（24 小时制选择器）；改了才出现取消 / 保存；下次同步时间；立即同步。同步排队或进行中时按钮显示“正在同步…”，每 3 秒重读一次，直到完成 |
| 上次同步 | 和网页同样的几行：相册、照片、按名字找到的、没建的相册、别人的照片、对上多张的、成员变化、等加入的成员；读不到照片的相册用黄色提示；失败时显示原因 |
| 没对上的 | “没对上的相册和照片：N 项”，点进去按相册分组：相册没建或读不到时写在相册名下面，照片写路径、原因、“我的 / 别人加的”；最多显示 500 张。App 里不做下载 CSV，要全部清单到网页下载 |
| 官方服务器 | `GET /synology/account` 是 404，显示“当前服务器不支持外部相册，需要 macOS 上的 Pixcellar 服务器” |
| 出错 | 用本地化的“无法绑定 NAS 账号”等提示，和网页一致 |

接口用新生成的 Dart 客户端（`SynologyApi`），在 `data/server/external_album.dart` 里转成 App 自己的模型，原因是枚举，App 不认识的新原因当“其他”。

## 手机 App：选择人物封面

之前只能在照片详情里长按人脸“设为人物封面”，人物页找不到。现在人物页右上角菜单多一项“选择人物封面”：打开这个人自己的照片（只含自己的，人脸都在这些照片上），点一张选中，再点另一张就换成另一张，点“完成”设为封面，头像随即刷新；关掉什么都不改。

时间线组件加了一个参数：选择模式下用哪个顶栏，默认还是原来的“已选择 N 项 / 完成”。

|---|---|
| 服务端单元测试（外部相册）：改了文字的提示 | 64 项通过 |
| 网页（外部相册设置）：NAS 的原话照常显示在错误下面 | 15 项通过 |
| App 接口封装：读账号、时间表和上次同步；没绑定时用默认时间；官方服务器 404 时为“不支持”，其他错误照常抛出；绑定时没有密码和验证码就不发；保存时间表；读没对上的清单；不认识的原因当“其他” | 新增 8 项通过 |
| App 设置页：官方服务器的提示；界面里没有“Synology”；三项填齐才能绑定，绑定后显示账号；要验证码时显示原因和 NAS 原话、填够位数才能再绑定、带上验证码；编辑时地址账号不变可沿用密码，改了账号就要密码；上次同步的几行，点进没对上的清单按相册分组并写原因；立即同步；时间表改了才保存；解除绑定先确认、之后回到绑定表单；地址规则；分组和 500 张上限 | 新增 11 项通过 |
| App 人物封面：菜单里有“选择人物封面”；选第二张时替换第一张，完成后返回第二张的 ID；没选时“完成”不能点；关掉返回空 | 新增 3 项通过 |
| App 全部测试、`flutter analyze`、`dart format` | 1676 项通过；没有问题。DCM 本机没装，没跑 |
| i18n 三个文件 prettier | 通过 |
