Immich self-hosted photos @VERSION@

Installs Immich on this Mac: backup and browsing of photos and videos, smart search (Chinese, English, Japanese), face recognition and text recognition, all running here, with no Docker, Homebrew or developer tools.

This is an unofficial community build for macOS, not made by the Immich team or FUTO: see the next page for its licenses and terms.

  • Needs an Apple silicon Mac (M1 or later), macOS @MACOS_MIN@ or later, and about @SIZE_GB@ GB free.
  • Installed for the user logged in, and runs in the background whenever they are. Log in as the user Immich is to run as before installing.
  • Immich installed already (the one-click install): its database, settings and library are taken over, nothing is lost.
  • The smart search, face and text recognition models are included: nothing is downloaded.

Installing takes a minute or two. Then http://localhost:2283 opens, where you create the admin account. The machine learning models are prepared in the background after that (10-15 minutes), the web UI working meanwhile.
