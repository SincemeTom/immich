Immich is running

  • Web UI: http://localhost:2283. In the phone app, the server is http://this-Mac's-IP:2283 (System Settings > Network shows the IP).
  • The first time a network share (NAS) is used, macOS asks whether node may access network volumes: click Allow.
  • Manage it in Terminal: immichctl status, immichctl logs, immichctl doctor (whether this Mac keeps it running unattended).
  • Logs: ~/Library/Logs/Immich; the installation's in install.log there.
  • Upgrade by installing a newer package: everything is kept.
  • Uninstall: immichctl uninstall removes the services and keeps the data; --purge deletes the database and settings too. The photo library is always kept.
